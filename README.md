Key Features:
Multiple accounts with unique account numbers and PINs
Login authentication with 3-attempt lockout mechanism
OTP verification for deposits, withdrawals, and PIN changes
Mini-statement showing last 20 transactions
Secure PIN change and balance checking
Menu-driven interface with input validation

Technologies & Concepts:
Java (OOP: Classes, Objects, Encapsulation)
Collections Framework: HashMap, Deque, ArrayDeque
Random Number Generation: OTP system
Exception-safe Input Handling with Scanner
Modular Class Design: BankAccount, OtpService, Bank, ATMApp

Designed, implemented, and tested the complete ATM system, ensuring secure authentication, transaction tracking, and usability.
